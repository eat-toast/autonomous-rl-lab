# 실험 자료

실험의 상태와 계획·결과는 [실험 목록](../docs/experiment_index.md), 폴더별 역할은
[프로젝트 구조 계약](../docs/project_structure.md)에서 확인한다.
각 ID 폴더의 README가 해당 주제의 자료 입구다.

## 2026-11-08 자료 이전

- 복구 태그: `codex/pre-study-layout-20261108` (이전 전 HEAD).
- 루트 실행 기록 21개, MLP의 `results/runs`, 진단, 검증 보존본, 콘텐츠 및 전용 도구를 소속 study로 이동했다.
- 66개 경로 묶음, 1,752개 파일, 285,560,628바이트를 이동 직후 SHA-256으로 대조해 모두 일치했다.
- 경로 수정이 필요한 코드·안내 문서를 제외한 원본 1,729개도 최종 대조에서 해시가 일치했다.
- 원본 JSON·로그·체크포인트·보고서·검증 스냅샷·콘텐츠 패키지의 내용을 바꾸지 않았다.
- 과거 위치와 현재 위치는 [경로 이전표](../docs/path_migrations.json) 및 각 README에 기록했다.
- 파일별 이전 전 해시와 검사 결과는 로컬 `.tools/layout-migration/`에 보존했다.
  이전 원본 경로를 포함한 JSON은 재작성하지 않고 공통 경로 해석기로 연결한다.
- 기존 게시물의 초안·ZIP은 게시 상태를 추정해 삭제하지 않고 함께 보존했다.
- `MLP-02`의 원본과 표시 이름용 `MLP-03`의 관계는 유지했다.

실험 재학습과 최종 테스트 평가는 수행하지 않았다. 경로와 도구 검증은 자동 테스트와
모듈 import·문법 검사, 로컬 링크 및 원본 해시 대조로 수행한다.
