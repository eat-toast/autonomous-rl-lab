# MLP-05-방문횟수와벽방향제외 (MLP5)

실행 승인 대기. 기준은 [MLP4](../MLP-04/README.md)의 seed 0·1·2 최종 체크포인트다. MLP4의 개발 검증은 7/8·7/8·7/8(21/24), 두 칸 왕복 2건, 충돌 87회였다.

MLP4의 14개 입력과 방문 횟수 min(count, 3) / 3을 유지하고, [MLP3의 벽 방향 제외](../MLP-03/mlp14_action_mask_plan.md)만 추가한다. 벽·경계 방향을 훈련 탐색, greedy 및 DQN의 다음 상태 타깃 최댓값 후보에서 제외한다. 막다른 곳에서는 열린 방향으로 되돌아갈 수 있다. 목표는 반복 충돌을 없애면서 성공률과 왕복 실패가 어떻게 바뀌는지 확인하는 것이다.

같은 16개 훈련 미로와 8개 개발 검증 미로의 순서, 보상, 모델, DQN 설정 및 100행동 한도를 유지한다. 동일 seed에서 MLP5를 새로 초기화하며 기준 모델은 기존 체크포인트를 사용한다. 0 및 매 500스텝을 평가하고, 마지막 20,000스텝의 동일 seed·미로별 성공 전환, 왕복, 충돌, 기타 실패, 성공 경로 효율을 기록한다. 최종 테스트는 사용하지 않는다.

제안하는 채택 기준은 개발 검증 21/24 이상, 어느 seed도 MLP4보다 낮지 않음, 충돌 0회, 왕복 실패 2건 이하이다. 기준 미달이면 MLP4를 유지하고 미완료 seed가 있으면 판정을 보류한다. 실행 전 벽·경계 제외와 막다른 길, 탐색·greedy·타깃의 일관성을 점검한다. 실행과 독립 검증 자료를 보존한다.

제안 예산은 RTX 4060 worker 1개, seed 0→1→2 순차, seed당 20,000스텝(총 60,000), soft 300초/hard 330초, 실행·집계·독립 검증 합계 30분, 재시도 0회다.
