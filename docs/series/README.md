## 기획 결정

- 김작가는 실험·검증 기록을 읽어 연재 방향을 정하고 이 목록과 제작 지시서만 관리한다.
- 인계 산출물은 제작 지시서다. 그 이후 제작·검수·업로드·게시 기록·보관은 인스타그램 담당이 맡는다.
- 1화는 사용자가 지정한 MLP 소개다. 다른 CNN 소개 자료를 1화로 연결한 이전 판단은 철회했다.
- 기본 관측의 결과와 실행 기준 충족을 설명하기 전에 방문 추가를 이미 진행한 조건처럼 제시하지 않는다.
- 기존 10장 유지 선택 뒤 사용자가 이야기 연결 문제를 제기했다. 그 지적을 반영해 구성 범위를 재검토한다.
- 2화는 기존 10장과 1화의 비교 예고를 반영해 방문 추가 결과까지 포함한다. 기본 관측 결과와 실행 기준 충족을 먼저 설명한다.
