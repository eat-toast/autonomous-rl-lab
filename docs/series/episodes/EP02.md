# EP02 · 제작 지시서 — 같은 미로에서 두 모델은 어디로 갔을까?

- 기획 상태: 인계 가능.
- 최종 갱신: 2026-11-08 (한국 시간).
- 주관 실험: MLP-01. 추가 학습이나 평가 없이 검증된 기존 결과를 사용한다.
- 제작·게시 상태와 기존 자료: [인스타그램 담당 기록](../../instagram_publications.md) 참조.

## 이번 화의 질문

기본 관측 모델은 실제로 어떻게 움직였고, 어떤 실패를 확인해 방문 추가 실험을 진행했을까?

## 앞 화에서 이어받는 내용

[1화 지시서](EP01.md)는 기본 관측 입력 10개, MLP 구조, 학습·평가 방법과 방문 추가의 조건부 실행 기준을 소개했다.
아직 성공률과 실제 왕복 집계, 방문 추가의 실행 여부는 설명하지 않았다.
첫 연결 문장 의도: ‘지난 화에서 소개한 기본 관측 모델을 평가했습니다. 먼저 실제 경로와 전체 결과를 살펴봅니다.’
방문 추가는 초반부터 이미 존재하는 비교 모델처럼 제시하지 않는다. 기본 관측의 결과와 실행 기준 충족을 설명한 뒤 등장시킨다.

## 구성 결정

기존 10장 유지 요청과 1화의 두 모델 비교 예고를 반영해 이번 화 안에서 방문 추가 결과까지 설명한다.
기본 관측 결과 → 왕복 실패 → 사전 기준 충족 → 방문 추가 실행 → 비교 결과의 연결을 명시한다.
이전의 ‘방문 추가를 다음 화로 넘길 수도 있다’는 미정 상태는 이 지시서로 정리한다. 후속 회차 번호는 새로 확정하지 않는다.

두 조건은 마지막 20,000스텝 모델을 탐색 없이 같은 고정 개발 지도 8개에서 평가한 결과다.

왕복은 실패한 시도의 마지막 8번 이동(위치 9개)을 기준으로 판정했다.
평균만 강조하지 말고 시드별 성공 수와 분모를 함께 유지한다. 표준편차는 검증 자료에 남기고 인스타그램용 HTML에서는 생략한다.

## 포함·제외

포함: 기본 관측의 실제 결과, 실패 관찰, 사전 기준 충족, 방문 추가의 의도·차이·결과, 동일 지도 사례와 해석 한계.
제외: CNN 비교, 다른 MLP 후속 조건의 성능, 중간 최고값을 최종 성능처럼 사용, 최종 테스트 성능, 인과·통계적 유의성·새 지도 일반화 단정.
‘방문 정보 때문에 성공률이 올랐다’, ‘기억을 얻어서 왕복을 해결했다’는 확정 표현을 쓰지 않는다.
‘같은 개발 지도에서 방문 추가 조건의 성공률이 더 높게 관찰됐다’는 범위로 설명한다.

## 확인과 인계

김작가 지침의 다섯 조건: 앞 화 근거 확인, 핵심 질문·연결 문장 작성, 입력 변경·새 학습 설명,
주장별 검증 근거 연결, 관찰·가설·후속 질문 구분을 완료했다.
추가 기획 확인 없이 이 지시서로 제작을 진행할 수 있다. 회차·주제·내용 범위 변경이 필요할 때만 김작가에게 돌린다.
인계 산출물은 이 지시서다. 표현·디자인·영상 편집·제작·검수·게시·보관은 인스타그램 담당이 맡는다.
