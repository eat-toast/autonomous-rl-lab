# EP01 · 제작 지시서 — 미로 AI는 무엇을 보고 길을 찾을까?

- 기획 상태: 인계 가능. 기존 1화 내용을 기준으로 사후 정리한 지시서.
- 최종 갱신: 2026-11-08 (한국 시간).
- 목적: 이미 제작한 회차의 기획 기준을 기록한다. 재제작·재게시를 지시하는 문서는 아니다.
- 제작·게시 상태와 최종 자료: [인스타그램 담당 기록](../../instagram_publications.md) 참조.

## 이번 화의 질문

미로 전체를 보여주지 않고, 주변 벽과 출구 방향만 알려줘도 AI가 길을 찾을 수 있을까?

## 앞뒤 이야기 연결

첫 회차이므로 선행 지식을 가정하지 않는다. 미로 규칙 → 모델이 보는 정보 → 행동 선택 → 학습과 평가 순서로 설명한다.
독자가 이 회차를 읽은 뒤에는 ‘기본 관측’의 의미와 다음 화 결과의 분모·평가 방법을 이해할 수 있어야 한다.
다음 화에서는 실제 경로와 기본 관측 결과를 먼저 보여주고, 조건을 충족해 방문 추가를 실행한 경위를 설명한다.

## 실험과 근거

- 주관 실험: MLP-01. 기본 관측 = MLP10, 방문 추가 = MLP14.
- 조건과 입력: [프로토콜](../../../studies/MLP-01/results/protocol.json).
- 검증 상태와 사실: [독립 검토](../../../studies/MLP-01/results/review.json), [검증 사실](../../../studies/MLP-01/results/verified_facts.json).
- 검증 보존 커밋: 44eafaf2fa5f218a745a5384b34fc671ddefa371.
- 내용 대조: 사용자 지정 1화 패키지의 9장·caption.txt·upload_preflight.md를 확인했다. 파일 위치와 게시 이력은 인스타그램 담당 기록에서만 관리한다.
- CNN 소개 자료는 이 회차의 근거가 아니다.

## 반드시 설명할 내용

| 항목 | 기획상 유지할 사실 |
|---|---|
| 미로·행동 | 10×10, 왼쪽 위 출발·오른쪽 아래 출구, 상·하·좌·우. 충돌 시 제자리이며 행동 횟수에 포함 |
| 기본 관측 | 주변 8칸의 벽·경계 여부와 출구까지의 행·열 차이 2개. 차이는 각각 9로 나눈 값 |
| 모델 | MLP 10→64→64→4. 두 은닉층에 ReLU, 출력은 네 방향의 행동 점수 |
| 행동 후보 | 벽·경계 방향을 미리 제외하지 않음 |
| 보상 | 일반 이동 -0.01, 충돌 -0.05, 출구 도착 +1 |
| 학습 | 같은 훈련 지도 16개, 학습 시드 0·1·2, 시드당 20,000 환경 스텝 |
| 평가 | 마지막 20,000스텝 모델, 고정 개발 지도 8개, 탐색 없이 평가. 조건당 3×8=24회이며 서로 다른 지도 24개라는 뜻이 아님 |
| 성공 판정 | 100번째 행동까지 출구에 도착하면 성공 |
| 후속 실험 계획 | 기본 관측의 두 칸 왕복 실패가 전체 24회 중 6회 이상이고 학습 시드 2개 이상에서 발생할 때만 방문 추가 실행 |
| 왕복 정의 | 실패한 시도의 마지막 8번 이동에 기록된 위치 9개가 서로 다른 두 칸을 번갈아 오가는 경우 |
| 최종 테스트 | 별도 지도 16개는 사용하지 않음 |

## 이야기 흐름

기존 9장의 역할을 기록한다. 구체적 문구·디자인은 인스타그램 담당의 범위다.

1. 질문: 미로 AI는 무엇을 보고 길을 찾을까?
2. 미로와 연구 질문: 주변 정보만으로 출구를 찾을 수 있을까?
3. 관측: 기본 입력 10개와 실제 시작점 예시.
4. 정책: MLP에서 네 방향 점수를 계산하는 흐름.
5. 학습: 공통 지도·학습량·보상.
6. 평가와 방문 추가 실행 기준: 계획과 실제 결과를 구분.
7. 훈련 지도 16개: 학습에 사용한 지도 범위.
8. 개발 검증 지도 8개: 결과를 읽는 평가 범위.
9. 미사용 최종 테스트 지도 16개: 이번 결과에 포함되지 않는 범위.

## 포함·제외 및 다음 화 인계

포함: 실험 구성, 입력과 행동, 학습·평가 방법, 조건부 후속 실험 계획.
제외: 성공률, 왕복 실패 실제 집계, 방문 추가 실행 여부 및 결과. 이들은 2화에서 설명한다.
다음 화 질문: 같은 미로에서 실제로 어떤 경로가 나왔고, 방문 정보를 더하는 실험은 왜 진행했을까?

## 확인과 인계

김작가 지침의 다섯 조건을 확인했다. 첫 회차이므로 직전 화 연결은 해당 없음이며, 나머지 조건은 위 근거와 범위로 충족한다.
