# MLP4 새 세션용 프롬프트

아래 블록을 읽고 예산과 판정 기준에 동의하면, 강화학습 프로젝트를 연 새 세션에 붙여넣는다.

```text
MLP-04-이웃방문횟수(MLP4) 실험을 서브에이전트들과 진행해줘. 이 메시지로 아래 조건과 예산에 한해 구현, 학습, 평가, 독립 검증, 결과 문서화와 2화 마무리 문구 초안 작성을 승인해. 결과 파일과 검증 기록까지 남겨줘.

AGENTS.md, docs/design.md, docs/experiment_index.md, docs/experiment_names.md, docs/agent_workflow.md를 읽고 이미 실행 중인 작업과 중복 여부를 확인해줘. 원본 대조군은 MLP2(MLP-02-이웃방문), studies/MLP-01/results/의 MLP14 seed 0·1·2 최종 체크포인트야. 독립 검증에서 7/8·5/8·7/8, 합계 19/24에 성공했고 두 칸 왕복 실패는 3건이었어. 직전 MLP3는 벽 방향을 제외했지만 같은 19/24였고 채택 기준에 못 미쳤으니 이번에는 MLP2에서 출발해줘.

변경 변수는 state 마지막 4개의 이웃 방문 표현이야. 북·동·남·서 순서로 방문 여부 0/1을 이번 에피소드에 해당 칸으로 실제 이동해 들어간 횟수 min(count, 3) / 3으로 바꿔줘. 시작 칸은 1회로 초기화하고 통로로 이동했을 때만 도착 칸의 횟수를 올려 다음 관측에 반영해줘. 벽·경계 방향은 0이고 충돌 때는 증가시키지 않아. 에피소드마다 초기화하고 훈련과 평가의 방문 기록을 분리해줘. 이동 전후 관측은 replay에 당시 값으로 저장해줘. 왕복 중에도 관측이 더 오래 구분되는지 검증하는 가설이야.

MLP2와 동일한 14개 입력 및 모델 구조, 보상, DQN 설정, seed, 100행동 한도와 실제 훈련 미로 16개·개발 검증 미로 8개의 원본·순서를 사용해줘. 행동 마스크나 재방문 금지 규칙은 추가하지 않아. 기존 MLP2를 재학습할 필요는 없고 MLP4는 같은 seed에서 새로 초기화해줘. 골까지의 직선거리 sqrt(행 차이² + 열 차이²)는 이후 별도 실험에서 채택한 조건에 한 개의 입력만 추가해 비교할 후보로 기록해줘. 이번 실행 범위는 MLP4까지야. 최종 테스트는 학습·평가·선택에 사용하지 않아.

RTX 4060 CUDA worker 1개로 seed 0→1→2를 순차 실행해줘. seed당 20,000 환경 스텝, 신규 학습 최대 60,000스텝, seed당 soft 300초/hard 330초, 실행·집계·독립 검증 전체 최대 30분, 재시도 0회야. 실패 시도도 예산에 포함해줘. CUDA가 불가능하거나 남은 예산이 부족하면 실제 상태와 원인을 남겨줘.

평가는 MLP2처럼 0 및 매 500스텝에 수행하고, 주 지표는 마지막 20,000스텝의 개발 검증 greedy 성공률이야. 24회 중 21회 이상 성공하고 어느 seed도 MLP2보다 낮지 않으면 MLP4를 후속 기준으로 채택해줘. 그 외에는 MLP2를 유지하고, 미완료 seed가 있으면 판정을 보류해줘. 같은 seed·미로의 성공/실패 전환, 100행동 실패 중 마지막 8개 이동(위치 9개)이 두 칸을 번갈아 오간 건수, 충돌, 기타 실패, 성공 경로 효율을 기록해줘. seed별 분모·평균·표본 표준편차·범위를 남기고, 탐색 훈련 return·훈련 greedy·개발 검증 greedy와 중간 최고값을 구분해줘.

조정자는 다음 역할을 서로 다른 서브에이전트에게 맡기고 파일 소유권을 지정해줘.

1. 실험설계·실행 담당은 agents/experiment.md를 따라 고유 묶음 ID와 전용 study 폴더를 만들고, 실행 전 계획과 Git 복구 지점을 기록해줘. 코드·설정·지도 해시, 실제 커밋과 변경 상태, 원장과 원본 로그를 보존해줘. 방문 횟수의 초기화·정규화·충돌·이동·replay 저장을 실행 전에 점검해줘.
2. 독립 검증 담당은 agents/results_review.md를 따라 실제 변경 범위, 예산, 복원한 체크포인트의 관측·행동·경로와 집계, 채택 판정을 원본과 대조해줘. 학습 중에는 검증 준비를 병렬로 해도 되지만 실행 중인 코드·설정과 원본은 수정하지 말아줘. 검증 결과는 review.json과 verified_facts.json에 남겨줘.
3. 콘텐츠 담당은 agents/instagram.md를 따라 독립 검증을 통과하고 로컬 Git에 보존된 사실로만 2화 마지막에 붙일 짧은 문구를 써줘. 결과와 다음 가설을 구분하고, 캡션을 만들면 #강화학습을 포함해줘. 공개 업로드는 이번 범위 밖이야.

조정자는 실험 목록과 이름 대응표를 갱신하고, 실행 종료 뒤 python scripts/commit_review.py --study <study 폴더>/results로 검증 자료를 로컬 Git에 보존해줘. 커밋에 실패하거나 검증이 통과하지 않으면 콘텐츠 인계를 멈추고 이유를 알려줘. 마지막에 완료 상태, 채택 여부, 핵심 수치, 검증 커밋과 결과 파일 위치를 알려줘.
```
