# 4단계 DQN 실험 결과와 역할 인계

2026-11-04. 학습량 → 탐색 기간 → 학습률 → FC 너비 순서의 개발 실험을 완료했다.
환경/State/reward는 고정했고 각 조건을 seed 0/1/2에서 20,000 환경 스텝씩 새로 학습했다.
훈련 미로 16개와 개발 검증 미로 8개를 동일하게 사용했다. 최종 테스트는 사용하지 않았다.

| 조건 | 변경 | 훈련 greedy 평균 | 검증 평균 ± seed 표본 표준편차 |
|---|---|---:|---:|
| 기존 예비 실험 | 2,000스텝 | 0% | 0% ± 0%p |
| A 학습량 | 20,000스텝으로 증가 | 4.17% | 4.17% ± 7.22%p |
| B 탐색 | A에서 탐색 감소 1,600→16,000스텝 | 54.17% | 12.50% ± 21.65%p |
| C 학습률 | B에서 0.001→0.0003 | 4.17% | 0% ± 0%p |
| D 모델 너비 | B에서 FC 64→128 | 35.42% | 4.17% ± 7.22%p |

C와 D는 모두 B를 기준으로 한 별도 비교다. D를 C의 학습률 설정에서 실행하지 않았다.
FC 64 모델은 210,212개, FC 128 모델은 415,332개의 파라미터다.
미리 고정한 마지막 checkpoint 검증 기준에 따라 B를 잠정 선택했다.
3개 seed와 8개 개발 미로의 결과이므로 일반적인 우수성이나 통계적 유의성을 주장하지 않는다.

## 보상 곡선

각 run에 에피소드별 실제 보상 합계와 최근 20개 이동평균을 저장했다.
에피소드 축과 환경 스텝 축을 모두 제공한다. 성공한 에피소드가 일찍 끝나므로 동일 스텝에서
완료 에피소드 수는 다를 수 있다. 마지막 미완료 에피소드는 평균에서 제외한다.
return은 탐색을 포함한 훈련 기록이다. 표의 훈련/검증 greedy 성공률은 탐색 없이 평가한 값이다.

결과 확인 서브에이전트가 summary/CSV/경로/체크포인트 메타데이터를 독립 대조했다.
`studies/20261104_four_steps/review.json`과 `verified_facts.json`의 상태는
`approved_for_dev_report`다. 새 최종 테스트 추론을 수행한 것은 아니다.

인스타 작성 서브에이전트는 그 사실 파일을 받아 캡션과 게시 안내를 검토한다.

카드뉴스·보상 그래프·결과표·캡션은 `exports/20261104_dqn_four_steps/`에 보존한다.

## 오류와 예산

B seed 1은 16,000스텝 모델 저장 중 파일 접근 오류로 실패했다.
원본을 보존하고 저장 재시도를 추가한 후 해당 seed만 처음부터 다시 학습했다.
완료 seed 0/2는 해시 일치 사본을 재사용했고, 재실행 seed 1의 첫 195개 완료 에피소드가
실패 시도의 원본 기록과 일치함을 확인했다.
새 연구의 실제 학습량은 사본 중복 제외 256,000스텝으로 복구 포함 상한 260,000 이내다.
study에 기록된 wall time은 약 1,173초로 상한 2,700초 이내다.
조건별 wall time은 바뀌는 데스크톱 부하에서 관찰한 값이므로 공정한 연산속도 비교로 해석하지 않는다.

## 다음 가설 (미실행)

원인을 과적합으로 확정하지 않는다. 다음 후보는 기존 검증 세트를 유지한 상태에서
훈련 미로 다양성만 16→64개로 늘려 같은 예산에서 비교하는 것이다.
