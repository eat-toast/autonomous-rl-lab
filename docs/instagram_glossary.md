# 인스타그램 공개 용어집

게시 전 검증 자료와 실험 설정을 대조하고, 같은 개념에는 카드·캡션·영상 전체에서 같은 표현을 쓴다. 기술 용어가 필요하면 처음 한 번 짧게 풀어 쓴다. 내부 ID와 공개 이름의 대응은 별도 제작 근거에 보존한다.

| 내부 용어 | 공개 권장 표현 | 확인할 점 |
|---|---|---|
| MLP10 | 기본 관측 | 주변 벽 8개와 출구까지의 행·열 차이 2개를 입력한다. |
| MLP14 | 방문 추가 | 기본 관측에 이번 에피소드의 상·우·하·좌 이웃 방문 여부 4개를 추가한다. |
| observation | 관측 / 모델이 받는 입력 | 미로 전체를 받는지, 주변 정보만 받는지 구분한다. |
| action masking | 행동 마스킹 / 선택할 행동 후보를 미리 거르는 방식 | ‘합법 행동’은 쓰지 않는다. 어떤 행동을 가리는지 구체적으로 적는다. MLP-01에서는 벽이나 지도 밖으로 향하는 행동도 선택 후보에 남아 있었다. |
| greedy evaluation, ε=0 | 탐색 없이 평가 / 점수가 가장 높은 행동을 선택 | 탐색이 포함된 훈련 기록과 구분한다. |
| training seed | 학습 시드(난수 초기값) | 지도 시드와 구분한다. 이후에는 ‘시드’로 줄여 쓸 수 있다. |
| episode | 한 번의 시도(에피소드) | 시작부터 도착 또는 행동 한도까지다. |
| environment step | 환경 스텝 / 환경에서 행동을 한 번 선택한 횟수 | 충돌 행동도 포함한다. 훈련 스텝과 재생 행동 수를 구분한다. |
| checkpoint | 체크포인트(저장된 모델) | MLP-01의 주 결과는 마지막 20,000스텝 모델이다. 중간 최고값과 구분한다. |
| reward / return | 행동 보상 / 한 시도의 누적 보상 | 누적 보상과 성공률을 바꿔 쓰지 않는다. |
| validation / final test | 개발 검증 / 최종 테스트 | 평가에 사용한 지도와 사용하지 않은 지도를 구분한다. |
| success rate / difference | 성공률(%) / 성공률 차이(%p) | 시드별 성공 건수와 분모를 표시한다. |
| sample SD | 표본 표준편차 | 실험 결과 검토용 지표다. 성공률의 시드 간 편차는 %p로 기록하고 인스타그램용 HTML에서는 생략한다. |
| two-cell oscillation | 두 칸 왕복 | MLP-01의 판정은 실패한 시도의 마지막 8개 이동(위치 9개)이다. |

공개 이름은 관측이나 설정의 차이를 설명한다. ‘개선형’, ‘기억하는 AI’처럼 효과나 능력을 먼저 단정하는 이름은 피한다.
