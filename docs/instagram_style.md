# 인스타그램 캐러셀 디자인 규격

MLP-01에서 사용한 과학 실험 노트 스타일을 시리즈 기본값으로 삼는다. 카드 수는 요청을 따른다. MLP-01처럼 한 화 6장이면 표지 1장과 본문 5장으로 구성한다.

- **출력:** 1080×1350 px, 세로 4:5, 카드별 RGB PNG. 화별 폴더에 01.png부터 순서대로 저장한다.
- **레이아웃:** 좌우 기본 여백 64 px. 상단에는 실험 시리즈명, 화·장 번호와 구분선을 둔다. 하단에는 구분선과 진행 표시만 둔다. 카드 하단에 ‘출처’ 라벨이나 파일명을 넣지 않는다. 원본 경로와 검증 커밋은 별도 제작 근거에 남긴다.
- **색:** 표지는 짙은 녹색 `#142B27`과 밝은 강조색 `#C9F487`. 본문은 종이색 `#F5F5EC`, 본문 글자 `#172925`. MLP-01의 기본 관측은 적갈색 `#A63826`, 방문 추가는 청록색 `#006D5E`로 고정한다. 색과 함께 조건 이름·숫자를 표시한다.
- **글자:** 맑은 고딕 계열. 제목 65–86 px, 본문 30–42 px, 주석 23–27 px를 기본으로 한다. 해시처럼 긴 식별자에는 21 px 이상 고정폭 글꼴을 쓸 수 있다. 한 장에는 핵심 주장 하나를 두고, 작은 글씨를 늘리기보다 내용을 나눈다.
- **도식:** 관측은 입력 블록, 정책은 층의 순서를 잇는 화살표, 결과는 같은 눈금의 막대그래프로 표현한다. 실제 재생 정지 화면은 원본 격자·저장 좌표를 사용하고 시작, 출구, 벽, 이동 방향을 표시한다. 반복 이동을 겹쳐 그리면 그 사실을 적는다.
- **검수:** PNG를 직접 열어 한글과 수학 기호, 줄바꿈, 잘림, 범례, 단위, 분모, 지도와 경로를 확인한다. 전체 미리보기에서 시리즈의 색과 장 번호가 일관적인지 확인한다.

## 업로드 전 검수

공개 업로드 전에 최종 업로드 묶음을 대상으로 다음을 확인하고, 확인 결과를 `upload_preflight.md`에 기록한다.

- 업로드할 ZIP을 새로 열어 카드 수와 파일 순서를 확인한다. 캡션이 같은 회차의 최종본인지 대조한다.
- 카드마다 실제 크기가 1080×1350 px이고 PNG가 정상적으로 열리는지 확인한다.
- 6장을 하나씩 전체 크기로 열어 글자·기호·줄바꿈·겹침·잘림을 본다. 특히 첫 장과 마지막 장의 상하단 여백과 하단 문구를 확인한다.
- 앱의 업로드 미리보기에서도 순서, 비율, 하단 잘림, 캡션을 확인한다. 잘림이 보이면 게시를 멈추고 이미지와 ZIP을 다시 만든다.
- 재업로드는 최종본 검수가 끝난 뒤 진행한다. 기존 게시물을 교체할 때에는 회차를 다시 확인하고 기존 1화를 삭제한 다음, 검수한 새 ZIP의 여섯 장과 캡션을 게시한다. 완료 후 게시물 미리보기에서 여섯 장을 다시 확인한다.
