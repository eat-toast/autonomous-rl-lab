# 실제 기록을 사용하는 픽셀 게임형 영상 제작법

## 채택 상태

2026-11-08 사용자에게 픽셀 게임형 시안의 스타일 채택을 승인받았다.
실제 이동 영상의 표현 기본값이며, 캐러셀 전체를 이 스타일로 바꾸라는 뜻은 아니다.

## 화면 구성과 표현

- 출력 기본값: 세로 1080×1920, 30fps, MP4 H.264, yuv420p, faststart. 음악·음성은 작업별로 정한다. 현재 시안은 무음.
- 상단: 짧은 질문 하나와 비교 조건. 질문은 이동이 시작될 때부터 표시한다.
- 가운데: 실제 격자·벽·출구를 유지한 게임 화면. 비교는 같은 크기·눈금·속도로 재생한다. 캐릭터는 작은 각진 얼굴, 벽은 타일 형태로 꾸민다.
- 하단: 종이색 해설창, 짧은 두 줄 이내의 장면 설명, 행동 수·평가 조건·진행 표시. 화면 하단 200px는 필수 정보 배치를 피하고 업로드 미리보기에서 UI 겹침을 확인한다.
- 색: 배경 #101b23, 패널 #203735, 설명창 #f5efd9, 기본 관측 #e37a60, 방문 추가 #65d4b5, 강조 #d3ed8c. 조건 이름을 함께 표시한다.
- 한글 가독성을 우선해 맑은 고딕 Bold를 사용한다. 제목 65–70px, 조건 41px, 해설 43px, 보조 설명 26–30px를 시안 기준으로 삼는다.
- 외부 릴스의 음악·캐릭터·이미지를 복사하지 않고 화면 구조와 이야기 전달 방식을 참고한다.

## 사용자 피드백을 반영한 편집 원칙

- 시작의 정지 타이틀 대기를 두지 않는다. 첫 프레임에 질문과 시작 위치를 보여주고 바로 이동한다.
- 마지막 행동 뒤 결과 확인에 필요한 짧은 시간만 둔다. 이 사례는 1초다. 자막 읽기에 더 필요하면 근거 있는 길이로 조정하되 무변화 구간을 길게 유지하지 않는다.
- v1의 시작 3초·마지막 4초를 제거한 v2는 11초다. 10초 실제 이동 + 1초 결과이며 100/30행동을 모두 유지한다.
- 짧게 만들기 위해 실제 행동을 몰래 생략하지 않는다. 반복 이동 압축·가속·일부 발췌는 적용 범위를 화면과 제작 기록에 표시한다.
- 한쪽이 먼저 끝나면 해당 최종 위치와 행동 수를 고정한다. 양쪽의 기록이 끝날 때까지 재생한다.

## 제작 절차

1. agents/instagram.md의 선행 절차에 따라 제작 지시서·공개 용어·독립 검증 자료와 승인 범위를 읽는다. 검증 게이트와 commit_review 성공 뒤 제작한다.
2. 저장 기록에서 지도·시드·모델·선택 이유·행동 수를 확인한다. 지도 해시와 경로를 대조하고 파일 SHA-256을 제작 기록에 남긴다. 새 학습·평가는 실행하지 않는다.
3. 대본은 질문 → 실제 이동 관찰 → 사례의 결과로 쓴다. 별도로 학습한 최종 모델 비교를 학습 세대 변화처럼 표현하지 않는다. 사례와 전체 성능을 구분한다.
4. PIL로 각 프레임을 그려 FFmpeg에 RGB rawvideo로 넘긴다. 원본 좌표 사이 선형 보간만 사용한다. 벽·출구·좌표·행동 판정은 꾸미지 않는다.
5. 동일 사례의 승인된 시안을 다듬을 때는 앞뒤 정지 구간만 프레임 단위로 자를 수 있다. 재인코딩하고 첫·도착·마지막 행동·끝 프레임을 확인한다.
6. MP4 전체 디코딩, 프레임 수·해상도·길이 확인, 인코딩된 프레임의 한글·잘림·지도·조건·행동 수 검수를 수행한다. 선택 사례와 기록을 다시 대조한다.
7. study별 exports의 해당 게시물 폴더에 버전·README·production.json을 남긴다. 게시 목록을 갱신하고 공개 업로드 요청과 보관 절차는 기존 지침을 따른다.

## 재현 가능한 예제

### 음악 선택과 적용

2026-11-08 사용자 선택: 이번 EP02 영상은 [Chill/Calming Chiptune Loop — Reganati](https://pixabay.com/music/electronic-chillcalming-chiptune-loop-527182/), 다음 영상에는 [Eternal Arcade — SlimeyFox](https://pixabay.com/music/trap-eternal-arcade-487325/)를 사용한다. 다음 회차 기획이나 게시 일정을 확정한 뜻은 아니다.
빠른 아케이드풍보다 느긋하고 차분한 배경음을 선호한다. 다음 제작 때도 이 취향을 기본값으로 삼는다.
음원 페이지와 라이선스를 사용 시점에 확인하고 URL·작가·취득일·파일 해시·발췌 구간·음량·페이드를 기록한다.
무음 영상은 보존하고 음악 적용본을 별도로 만든다. 이번 설정은 첫 11초, -20 LUFS 정규화 목표, 마지막 0.7초 페이드아웃이다.
음악 적용 스크립트는 `studies/MLP-01/scripts/add_pixel_reel_music.py`, 출력·근거는 해당 게시물의 `pixel_music_v1/`에 있다.
원본 음원의 단독 재배포를 피하고 Git에는 제작 코드·문서만 추적한다. 청음과 음량은 담당자가 확인하고 최종 사용자 미리보기로 전달한다.
음악 작업 전체는 인스타그램 담당 소관이다. [공용 음악 목록](instagram_music_library.md)을 먼저 읽고 `assets/instagram/audio/<ID>/`의 원본을 재사용한다. 기존 게시물의 제작 근거는 이동하지 않는다.

- 첫 렌더: `studies/MLP-01/scripts/render_pixel_reel.py`.
- 사용자 피드백 편집: `studies/MLP-01/scripts/trim_pixel_reel.py`.
- 제작물: `studies/MLP-01/exports/instagram_MLP-01_EP02/pixel_pilot_v2/`.
- 실행은 프로젝트 루트에서 Python 3.12와 Pillow, `.tools/imageio_ffmpeg`를 사용한다.
- 예제 코드는 MLP-01의 첫 개발 지도·학습 시드 0·100/30행동에 고정돼 있다. 다른 연구에 그대로 실행하지 말고 출처·목표·크기·조건 검증을 해당 기록에 맞춰 바꾼다. 공통 규칙을 수정할 필요는 없다.
