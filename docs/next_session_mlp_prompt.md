# MLP-01 새 세션용 프롬프트

아래 블록을 강화학습 프로젝트를 연 새 세션에 붙여 넣는다.

```text
이 강화학습 프로젝트에서 실험 MLP-01을 진행해줘. 이 메시지로 아래 범위의 구현, 학습, 평가, 독립 검증, 결과 문서화를 승인한다. 계획 설명에서 멈추지 말고 결과와 근거 파일까지 남겨줘.

먼저 AGENTS.md → docs/experiment_index.md → docs/mlp_feelers_study_plan.md 순서로 읽어줘. MLP-01의 상태와 이미 작성된 코드, 기존 run, 진행 중인 작업을 확인해 중복 실행을 피하고 이어서 진행해줘. 계획서와 이전 실험 결과는 보존하고 MLP-01의 실행 프로토콜과 산출물은 별도로 기록해줘.

첫 단계는 MLP10이다. 입력은 주변 벽 8개와 출구까지의 행·열 차이 2개다. 계획서에 정한 방향 순서, 벽·경계 표시, 좌표 정규화를 사용해줘. 모델은 64→64 은닉층과 상하좌우 4개 출력을 쓰고 합법 행동 mask 없이 학습한다. 기존 CUDA B와 같은 훈련 지도 16개·개발 검증 지도 8개, reward-v1, seed 0·1·2를 사용하고 나머지 설정도 계획서를 따라줘.

MLP10의 세 seed를 완료한 뒤 마지막 체크포인트의 개발 검증 24회를 확인해줘. 100행동으로 실패하고 마지막 8개 이동이 두 칸을 번갈아 오가는 평가가 6회 이상이며, 그런 실패가 2개 이상 seed에서 나왔을 때만 MLP14를 실행해줘. MLP14는 상하좌우 이웃 칸을 이번 에피소드에서 밟았는지 나타내는 4개 입력을 추가하고, 같은 seed로 처음부터 학습한다. 기준 미충족은 MLP14 미실행, MLP10의 미완료 seed는 진입 판단 보류로 기록해줘.

RTX 4060 CUDA worker 1개, seed당 20,000 환경 스텝, 단계당 60,000스텝, 합계 최대 120,000스텝으로 진행해줘. 재시도 0회, seed soft 300초·hard 330초, 실행·집계·독립 검증 최대 60분을 적용한다. 구현과 단위 검증은 별도 기록한다. 기존 최종 테스트 세트는 사용하지 말고, CUDA 사용 불가나 예산 중단 시 원인과 실제 완료 범위를 기록해줘. 실행 전 Git 복구 지점과 실제 코드·설정·지도 식별 정보를 남겨줘.

별도의 검증 담당 서브에이전트에게 체크포인트 복원, 관측·경로·지표 대조, MLP14 진입 판단, 예산 확인을 맡겨줘. seed별 성공률, 실패 유형, 충돌·경로 효율, 실제 학습량과 시간을 정리하고, 탐색 훈련 return과 greedy 평가, 마지막 모델과 중간 최고값을 구분해줘. 과거 CNN은 관측 범위와 모델 구조가 함께 다른 참고 결과로 다뤄줘.

studies/MLP-01/results/에 계획서에 명시한 결과 파일과 실제 재생에 필요한 seed·지도·체크포인트·행동 기록을 저장해줘. docs/experiment_index.md의 MLP-01 항목에 실행 결과와 검증 상태를 연결하고, 검증 뒤 AGENTS.md의 commit_review.py 절차로 자료를 로컬 Git에 보존해줘. 인스타그램용으로는 검증된 사실과 재생 근거까지만 정리해줘. 게시물 제작과 업로드는 별도 요청에서 다룬다.
```
